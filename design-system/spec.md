# Spec — VEC Design Studio
Status: proposta visual; MVP local autorizado, migração de produção não autorizada.

## Aceite
- Inventário navegável com IDs estáveis, fonte e status por tela.
- Preview CSS real em 1920×1080, 2560×1440, 3840×2160 e 390×844, escalado para caber no catálogo.
- Tokens candidatos 60/30/10, componentes compactos e alvos mobile de 44 px.
- Fixtures fictícias, sem autenticação, API ou tiles externos.
- Seis protótipos iniciais; completar demais frames e estados em PRs posteriores.
- Validar teclado, contraste, responsividade e regressão Playwright antes de aprovação visual. Não declarar testes não executados.

## Fases
1. Catálogo e foundations; 2. mapa e pessoas; 3. demais telas; 4. estados e motion; 5. regressão visual; 6. migração incremental após ADR e aprovação.
