# Área VEC — Claude Code

Leia e siga **`AGENTS.md`** na raiz deste repositório. Esse é o contrato
compartilhado entre Claude Code e Codex. Não crie regras paralelas.

Antes de iniciar uma tarefa:
1. Consulte `AGENTS.md`, `specs/README.md`, as ADRs relevantes e a Spec selecionada.
2. Verifique a Issue e suas dependências em `graph.json`.
3. Leia `specs/<spec>/handoff.md`, se existir, para recuperar o estado entre agentes.
4. Use `.github/agents/planner.md`, `developer.md` e `reviewer.md` conforme o papel.
5. Trabalhe em branch/worktree isolado, com uma tarefa por PR.

O histórico de conversa do Codex não está disponível automaticamente aqui.
Confie apenas em arquivos versionados, Issues, commits e evidências verificáveis.
